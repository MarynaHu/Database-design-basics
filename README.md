# Лабораторна робота 1

Цей проєкт є консольним застосунком для обліку та керування транспортними засобами компанії.

## Основні можливості

- **CRUD операції:**
  - **C**reate: Додавання нових транспортних засобів до системи.
  - **R**ead: Отримання списку всіх авто (з підтримкою **пейджингу** — посторінкового виводу) та пошук за ID.
  - **U**pdate: Редагування існуючих записів.
  - **D**elete: Видалення авто з бази.
- **In-Memory Storage:** На даному етапі дані зберігаються в оперативній пам'яті (словник `dict` для швидкого доступу).
- **Підготовка до PostgreSQL:** Завдяки патерну Репозиторій (`VehicleRepository`), бізнес-логіка відділена від логіки збереження даних. Для переходу на БД достатньо буде додати новий клас `PostgresVehicleRepository` без зміни основного коду програми.
- **Unit-тестування:** Логіка роботи зі сховищем покрита автоматизованими тестами, щоб уникнути ручного перетестування при внесенні змін.

## Запуск проєкту

**Вимоги**:
- Встановлений Python 3.7 або новішої версії.
- Додаткові бібліотеки встановлювати не потрібно (використовуються лише вбудовані модулі).

**Інструкції щодо запуску коду**:

1. Відкрийте термінал / командний рядок.
2. Активація віртуального середовища через термінал:
   ```
   python -m venv .venv
   .venv\Scripts\activate
   ```
3. Перехід до папки з проєктом:
   ```
   cd folder_path/lab1_fleet
   ```
4. Запуск головного файлу:
   ```
   python main.py
   ```
5. Дотримуйтесь інструкцій в інтерактивному консольному меню.

##   Модель даних (Vehicle)  
Кожен транспортний засіб зберігає таку інформацію:  
  •id (int): Унікальний ідентифікатор (генерується автоматично).  
  •make (str): Марка автомобіля.  
  •model (str): Модель автомобіля.  
  •license_plate (str): Державний номерний знак.  
  •year (int): Рік випуску.
