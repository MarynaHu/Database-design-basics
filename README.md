# Лабораторна робота 3

На основі створеної таблиці (див Lab_2) створено уявлення(view), скалярну та табличну функцію які б відображали якийсь бізнес процес, процедуру для генерації нових даних, а також таблицю для ведення історій і трігер який би її заповнював. Використовуючи оператор UNION ALL(або UNION) вивести інформацію про існуючі та видалені сутності/рядки з системи 

## Файл містить
-Створено таблицю `vehicles_history` та тригер `trg_vehicle_audit`, який автоматично відслідковує дії (`INSERT`, `UPDATE`, `DELETE`) у головній таблиці `company_vehicles`. Дані до зміни зберігаються у гнучкому форматі **JSONB**, що дозволяє ніколи не втрачати історію парку.
-Створено уявлення `view_active_fleet`, яке надає швидкий доступ лише до тих автомобілів, що зараз перебувають на маршрутах (статус 'Active' та пробіг > 0), приховуючи зайві технічні деталі.
- **Скалярна функція:** `calculate_vehicle_tax(year)` — розраховує податок на транспортний засіб залежно від його віку.
- **Таблична функція:** `get_vehicles_by_mileage(min, max)` — повертає готовий набір даних (таблицю) для пошуку машин у заданому діапазоні пробігу.
- Створено збережену процедуру `generate_vehicles(n)`, яка генерує задану кількість тестових автомобілів з випадковими номерами та роками випуску.

## Запуск проєкту

### **Технології**:
- **Система управління базами даних**: PostgreSQL.
- **Інструментарій:** pgAdmin 4 або psql.

### **Використання**:

**1. Згенерувати нові авто:**
```sql
-- Генерує 7 нових транспортних засобів
CALL generate_vehicles(7);
```

**2. Перевірити роботу тригера видалення:**
```
-- Видалити будь-яке авто (наприклад, з id = 1)
DELETE FROM company_vehicles WHERE id = 1;

-- Перевірити таблицю історії
SELECT * FROM vehicles_history;
```
**3. Переглянути актуальні та видалені авто (UNION ALL):**
```
SELECT full_name, license_plate, 'Current' as source_status
FROM company_vehicles
UNION ALL
SELECT (old_data->>'full_name')::varchar, (old_data->>'license_plate')::varchar, 'Deleted'
FROM vehicles_history
WHERE action_type = 'DELETE'
ORDER BY source_status;
```
