# Лабораторна робота 2

Таблиця для обліку та керування транспортними засобами компанії. 

## Файл містить
- Створення таблиці керування транспортними засобами компанії, з корректно обраними типами даних для колонок.
- Написано запити для заповнення таблиці одним значенням а також N новими записами використовуючи цикл while.
- Написано загалом 20 різних запитів використовуючи select, update, delete і комбінуючи FETCH(top), offset, order by, like, in, is null, is not null, and, or, not, between.

## Запуск проєкту

**Технології**:
- **Система управління базами даних **: PostgreSQL.
- **Інструментарій:** pgAdmin 4 або psql.

**Використання**:

### 1. Створення таблиці та генерація даних
Відкрийте скрипт у pgAdmin (або іншому редакторі для PostgreSQL). Спочатку виділіть мишкою та виконайте верхню частину коду:
- Команду `CREATE TABLE` для створення структури.
- Блок `DO $$...$$` з циклом `WHILE` для автоматичної генерації початкових даних (10+ записів з різними характеристиками).

### 2. Виконання тестових запитів
У другій половині файлу знаходяться 20 різнопланових запитів (`SELECT`, `UPDATE`, `DELETE`). 
**Важливо:** Не запускайте весь код одночасно! Щоб побачити результат кожної окремої дії, виділяйте мишкою один конкретний запит (до крапки з комою `;`) і натискайте кнопку виконання (F5).

Ці запити демонструють роботу з:
- **Фільтрацією:** `WHERE`, `LIKE`, `IN`, `BETWEEN`, `IS NULL`.
- **Сортуванням та лімітами:** `ORDER BY`, `OFFSET`, `FETCH FIRST`.
- **Логічними операторами:** `AND`, `OR`, `NOT`.
- **Оновленням та видаленням:** `UPDATE` та `DELETE` за складними умовами.
